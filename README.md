# Pesticide Degradation Analysis

Code and input data for the pesticide degradation analysis.

## Contents

- `final_notebook_2models_xgboost.ipynb` — Main notebook for model training and evaluation using XGBoost.
- `postprocess_cluster_errors.ipynb` — Notebook for post-processing and analysing prediction errors.
- `config.json` — Analysis configuration.
- `extraction_main.xlsx` — Extracted study data.
- `EpiSuite_BioWin_results_clean.xlsx` — Cleaned EPI Suite BIOWIN results.
- `model_df.pkl` — Prepared modelling dataset.

## Usage

Keep all files in the same directory. Open the notebooks in Jupyter and review the configuration and file paths before running.

Generated outputs are not included in this repository.
